# Digital Clock JAVA 🕒

A simple and elegant Digital Clock application developed using Java. This project displays the current time in a digital clock format with a clean and user-friendly interface.

## Features
- Real-time digital clock display
- Displays current system time
- Simple and user-friendly interface
- Developed using Java
- Created using NetBeans IDE

## Technologies Used
- Java
- NetBeans IDE

## Project Demo

## Purpose
This project demonstrates Java programming concepts and GUI development while creating a functional digital clock application.
